Entities and process flow

This page shows the model and the flow from my pen and paper notes. The flow follows the latest sketch, where an agent with a skill file replaced the ingestion agent.

Process flow

Sources → Ingestion → Processing

Information is pulled by any means and stored as a raw dump in a table. Processing then labels and tags it with rules, LLMs and agents. Records with a high confidence score go straight to the feed. Records with a low score wait for human review.
